# Личный сайт Артёма Зарипова

## Как открыть
1. Распакуйте архив в удобную папку.
2. Откройте Visual Studio Code.
3. Выберите **Файл → Открыть папку** и укажите `artem_zaripov_site`.
4. Откройте `index.html`.
5. Чтобы запустить сайт в браузере, установите расширение **Live Server** и нажмите правой кнопкой на `index.html` → **Open with Live Server**. Либо просто откройте `index.html` двойным щелчком в проводнике.

## Что изменить под себя
- В `index.html` измените тексты, добавьте настоящую ссылку на Telegram и другие контакты.
- Блок «ВАША ФОТОГРАФИЯ» — это заглушка. Положите фото в папку `images` и при желании замените блок на `<img src="images/me.jpg" alt="Артём Зарипов">`.
- В `styles.css` можно изменить цвета и внешний вид.
- Сайт адаптируется под телефоны и компьютеры. Для шрифтов из Google Fonts при первом открытии нужен интернет; без него останется системный шрифт.
